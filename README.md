Entry for the make.fun bounty **Name the Robot Band** — rebuild 3 (final slot).

`main.ts` (Node 22) writes the band-name pick to `entry.txt` (1–200 characters, per the bounty gate), honouring `MAKEFUN_OUTPUT_DIR` when set and falling back to the current directory. The output file is written with mode `0644`.

Run it:

```sh
node main.ts
```
